# Jeu-biblique-emoji

Ce dépôt contient maintenant une page web simple permettant de créer un PDF à partir d'un texte copié-collé.

## Utilisation

1. Ouvrez `index.html` dans votre navigateur.
2. Collez votre texte dans la zone dédiée.
3. Choisissez un nom de fichier.
4. Cliquez sur **Générer le PDF**.

Le PDF se télécharge automatiquement.
